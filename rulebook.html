Rulebook v0.1 — DRAFT for approval

Built entirely from the TC Manager's Question Round 1 answers (GitHub issues #10–#18, answered 2026-08-19). Each rule is condition → action, with a gate: AUTO = the Manager worker may act on an exact match; HUMAN = staged for a person to handle or approve. The bracket after each rule is the answer it came from — click any topic heading to see the original answer thread. Nothing gets built until this page is approved.

How to read this page

Every answer the manager gave was converted into one or more written rules. The Manager worker will only ever act on an exact match to an AUTO rule — anything that doesn't match a rule exactly escalates to a person. If a rule below is wrong, say so now (a comment on the topic's GitHub thread is perfect); once approved, this becomes Rulebook v1.0 and is what the system runs on.
